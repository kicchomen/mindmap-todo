# MindMap Todo

マインドマップ形式でタスクやアイデアを視覚的に整理するためのウェブアプリケーションです。

## 主な機能

### マインドマップ機能
- ノードの追加・編集
- ノードの折りたたみ（子孫ノードの表示/非表示）
- ノード検索機能
- ズーム・パン操作

### UI/UX
- 左側ナビゲーションバー
- ヘッダー検索
- サイドパネルのツリービュー
- モダンで直感的なデザイン

## 技術スタック

- TypeScript
- React
- Tailwind CSS
- React Flow
- Material UI Icons
- Zustand

## 開発環境のセットアップ

```bash
# リポジトリのクローン
git clone <repository-url>

# 依存関係のインストール
cd mindmap-todo
npm install

# 開発サーバーの起動
npm run dev
```
