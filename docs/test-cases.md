## 1. ユニットテスト

### 1.1 NavigationBarコンポーネントテスト

#### TC-NAV-001: ナビゲーションボタン表示テスト
**目的**: ナビゲーションバーに必要なボタンが正しく表示されることを確認する
**前提条件**: なし
**テストステップ**:
1. NavigationBarコンポーネントをレンダリングする
2. アカウントボタンの存在を確認する
3. プロジェクト一覧ボタンの存在を確認する
4. ツリービューボタンの存在を確認する
**期待結果**: 3つのボタンがすべて正しくレンダリングされる

#### TC-NAV-002: アクティブ状態切り替えテスト
**目的**: ボタンクリック時にアクティブ状態が正しく切り替わることを確認する
**前提条件**: NavigationBarコンポーネントがレンダリングされている
**テストステップ**:
1. アカウントボタンをクリックする
2. アカウントボタンがアクティブ状態になることを確認する
3. プロジェクト一覧ボタンをクリックする
4. プロジェクト一覧ボタンがアクティブ状態になり、アカウントボタンが非アクティブ状態になることを確認する
**期待結果**: クリックしたボタンのみがアクティブ状態になる

#### TC-NAV-003: ツールチップ表示テスト
**目的**: ボタンホバー時にツールチップが正しく表示されることを確認する
**前提条件**: NavigationBarコンポーネントがレンダリングされている

1. アカウントボタンにマウスをホバーする

## 5. テスト実装サンプル

### 5.1 Jest + React Testing Libraryによるユニットテスト例

```tsx
// NavigationBar.test.tsx
import { render, screen, fireEvent } from '@testing-library/react';
import NavigationBar from '../components/layout/NavigationBar';

describe('NavigationBar', () => {
  test('renders navigation buttons', () => {
    render(<NavigationBar />);
    
    expect(screen.getByTestId('account-button')).toBeInTheDocument();
    expect(screen.getByTestId('projects-button')).toBeInTheDocument();
    expect(screen.getByTestId('tree-view-button')).toBeInTheDocument();
  });
  
  test('changes active state on button click', () => {
    render(<NavigationBar />);
    
    const accountButton = screen.getByTestId('account-button');
    const projectsButton = screen.getByTestId('projects-button');
    
    fireEvent.click(accountButton);
    expect(accountButton).toHaveClass('bg-orange-100');
    expect(projectsButton).not.toHaveClass('bg-orange-100');
    
    fireEvent.click(projectsButton);
    expect(accountButton).not.toHaveClass('bg-orange-100');
    expect(projectsButton).toHaveClass('bg-orange-100');
  });
});
```

### 5.2 Cypressによる統合テスト例

```js
// search.spec.js
describe('Search Functionality', () => {
  beforeEach(() => {
    cy.visit('/');
    // マインドマップのセットアップ（必要に応じて）
  });
  
  it('highlights nodes matching search query', () => {
    // 検索実行
    cy.get('input[placeholder="ノードを検索..."]').type('テストノード');
    cy.get('form').submit();
    
    // ハイライト確認
    cy.get('.search-highlighted').should('exist');
    
    // クリア

  });
});
```

## 6. テスト環境セットアップ

### 6.1 Jest + React Testing Library

```bash
# インストール
npm install --save-dev jest @testing-library/react @testing-library/jest-dom @testing-library/user-event

# jest.config.jsの設定
module.exports = {
  testEnvironment: 'jsdom',
  setupFilesAfterEnv: ['<rootDir>/jest.setup.js'],
  moduleNameMapper: {
    '\\.(css|less|scss)$': 'identity-obj-proxy',
  },
};

# テスト実行
npm test
```
