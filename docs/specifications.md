# MindMap Todo アプリケーション仕様書

## 1. 概要

MindMap Todoは、マインドマップ形式でタスクやアイデアを視覚的に整理するためのウェブアプリケーションです。ノードの追加、編集、折りたたみ、検索などの機能を備え、直感的なインターフェースでユーザーの思考整理をサポートします。

## 2. 技術スタック

### コア技術
- TypeScript: ^5.0.0
- Node.js: ^20.0.0

### フロントエンド
- React: ^18.2.0
- Tailwind CSS: ^3.4.17

- Material UI Icons: ^1.10.0

- ESLint: ^8.56.0

## 3. 機能仕様

### 3.1 ナビゲーション・レイアウト

#### 3.1.1 左側ナビゲーションバー
- **位置**: 画面左端に固定（高さ100%）
- **幅**: 16px
- **背景**: 半透明白（bg-white/95）、backdrop-blur-sm効果
- **枠線**: 右側に2pxのグレー線（border-r-2 border-gray-300）
- **コンテンツ**:
  - アプリロゴ（上部）
  - アカウントボタン（AccountCircleIcon）
  - プロジェクト一覧ボタン（FolderIcon）
  - ツリービューボタン（AccountTreeIcon）
- **視覚効果**:
  - アクティブなアイテム: オレンジ背景（bg-orange-100）、オレンジテキスト（text-orange-600）
  - 非アクティブアイテム: グレーテキスト（text-gray-600）、ホバー時に薄いグレー背景（hover:bg-gray-100）
  - ツールチップ: 各ボタンにホバーすると機能名を表示

#### 3.1.2 ヘッダー
- **位置**: 上部固定（fixed top-4 left-20）
- **幅**: 計算式で最適化（w-[calc(100%-5rem-2rem)]）
- **デザイン**:
  - 丸形（rounded-full）
  - 半透明白背景（bg-white/90）、backdrop-blur-sm効果
  - 影効果（shadow-md）
  - 2pxのグレー枠線（border-2 border-gray-300）
- **コンテンツ**:
  - 左側: アプリ名とアイコン
  - 右側: 検索フォーム

#### 3.1.3 サイドパネル
- **位置**: 左側固定（fixed top-24 left-20）
- **サイズ**: 最大幅64px（max-w-xs w-64）、最大高さは画面の高さから調整（max-h-[calc(100vh-140px)]）
- **デザイン**:
  - 大きな角丸（rounded-3xl）
  - 半透明白背景（bg-white/95）
  - 影効果（shadow-md）
  - 2pxのグレー枠線（border-2 border-gray-300）
  - スクロール可能（overflow-auto）
- **コンテンツ**:
  - ヘッダー: "Todo ツリー"
  - ツリー構造でノードを表示（非表示ノードはフィルタリング）

### 3.2 マインドマップ機能

#### 3.2.1 ノード
- **デザイン**: 丸みを帯びた長方形、白背景
- **機能**:
  - ラベル編集: クリックして直接編集
  - 子ノード追加: ノードからドラッグして新規ノード作成
  - 折りたたみ: 子ノードを持つノードに表示される目のアイコンで制御

#### 3.2.2 ノードの折りたたみ機能
- **トリガー**: 目のアイコン（VisibilityIcon/VisibilityOffIcon）をクリック
- **動作**:
  - 折りたたみ時: 子孫ノードと接続線を非表示
  - 展開時: 子孫ノードと接続線を表示
- **視覚効果**:
  - アイコン位置: ノードラベルの右側
  - ホバー時: 透明度変更（opacity: 0.7 → 1.0）
  - トランジション効果: 滑らかな視覚的フィードバック

#### 3.2.3 検索機能
- **UI**:
  - 検索フォーム: ヘッダー右側に配置
  - 検索アイコン: 24pxサイズ（左側）
  - クリアボタン: 24pxサイズ（右側、入力時のみ表示）
  - 入力フィールド: 通常時56px幅、フォーカス時72px幅
- **機能**:
  - リアルタイム検索: 入力に応じて結果を表示
  - 結果ハイライト: 一致ノードにオレンジ色の枠線とパルスエフェクト
  - 自動センタリング: 最初の一致ノードに自動的にビューを移動
  - リセット: クリアボタンで検索結果をリセット

### 3.3 操作性

#### 3.3.1 ズーム・パン
- ズーム範囲: 0.2倍〜1.5倍
- パン: マウスドラッグでキャンバス移動
- コントロール: 右下にズーム・パンコントロールを表示

#### 3.3.2 ノード選択
- サイドパネルからノード選択: クリックで該当ノードにビューをセンタリング
- 検索結果からノード選択: 検索結果ハイライトノードを選択可能

## 4. UI/UXデザイン原則

### 4.1 カラースキーム
- **プライマリカラー**: オレンジ（アクセントカラー）
- **セカンダリカラー**: グレー（UI要素の枠線、非アクティブ状態）
- **背景色**: 白/半透明白（コンポーネント背景）、薄いスレート（キャンバス背景）

### 4.2 視覚的階層
- 重要なアクション: オレンジ色でハイライト
- 二次的なUI要素: グレートーン
- 情報の整理: 適切な間隔とグループ化

### 4.3 アクセシビリティ
- 十分なコントラスト比
- 明確なフォーカス状態
- ツールチップによる補助情報
